# Что реально можно объединить с 112

Проверено 20.09.2026. Вывод: единый пользовательский вход возможен;
прямую отправку карточек в Систему-112 пока нельзя обещать.

## Подтверждено источниками

МЧС публикует методические материалы по созданию региональных Систем-112:
https://mchs.gov.ru/dokumenty/1078 . Официальные материалы описывают
интеграцию с диспетчерскими системами и ЭРА-ГЛОНАСС:
https://moscow.mchs.gov.ru/uploads/resource/2022-02-03/elektronnye-knigi_1643874867833020310.pdf .
Эти материалы объясняют архитектуру, но не дают нашей команде доступ.

В официальном описании приложения МЧС есть передача координат при отправке
сообщения в экстренные службы:
https://mchs.gov.ru/uploads/resource/2024-10-15/mobilnoe-prilozhenie-mchs-rossii_17290039151041433541.pdf .
Это возможность официального приложения, не доказательство открытого API для стороннего бота.

В проверенных источниках не найден публичный API с самостоятельной выдачей
ключа сторонней команде для создания обращений, получения статусов и доступа
к «единой базе 112». Это не доказывает отсутствия договорных интеграций.

## Три уровня реализации

1. **Сейчас:** отдельный экстренный раздел, номер 112, явное отсутствие отправки.
   В мини-приложении можно реализовать переход к набору номера с запасным
   отображением номера; поддержку перехода надо проверить на клиентах MAX.
2. **На хакатоне:** локальная демонстрационная очередь диспетчера, если она
   нужна для показа будущей интеграции. Каждый экран и статус должны говорить
   «демонстрация, не отправлено в 112». Сейчас такой адаптер ещё не реализован.
3. **Реальный пилот:** выяснить условия у оператора Системы-112 выбранного
   региона и организаторов, получить техническую документацию и тестовый доступ.
   После этого реализовывать адаптер по реальному контракту, а не придуманному API.

## Что спросить у организаторов и регионального оператора

Готовый текст для команды; никому автоматически не отправлялся:

> Мы разрабатываем для хакатона бота в MAX по вопросам ЖКХ и хотим проверить
> возможность пилотной интеграции с региональной Системой-112.
> Есть ли партнёр или тестовый контур для передачи карточек происшествий?
> Возможен ли доступ сторонней команды, какие нужны согласования и документы?
> Доступны ли спецификация API, тестовые учётные данные и контакт технического специалиста?
> Какие данные разрешено передавать, как подтверждается приём оператором,
> предусмотрены ли обратные статусы, защита от повторов и регламент при сбое?
> Можно ли в рамках хакатона демонстрировать интеграцию на тестовом контуре?

Без ответа на эти вопросы не утверждать в презентации «интегрировано с 112».
Для Госуслуги Дом отдельно нужны проверка доступного интерфейса и прав доступа:
токен MAX не предоставляет доступ ни к одной из этих систем.
